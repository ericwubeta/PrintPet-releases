# PrintPet · 打印小监工（桌宠）

让精灵陪你看 3D 打印进度。支持拓竹云只读监控、角色动作与声音、桌面提醒，以及自行配置的 AI 聊天。

本仓库提供 Windows 安装包和签名更新清单，软件源码单独维护。官网：[printpet.684159.xyz](https://printpet.684159.xyz/)。

## 0.5.2 · 六位打印伙伴

大肥鱼、Claude Code、Codex 白、Codex 黑，加上芙宁娜、胡桃。两位新伙伴具有 A 系列、封箱机及通用打印道具动作、专属短语音与独立聊天历史；动作播放后停留。角色仍由用户全局选择。

真实进度、剩余时间和设备数据来自遥测；含固定数字的录音只用于明确标注的素材演示。程序仅发送状态查询，不提供打印、暂停、加热或运动控制。

## 安装与更新

从 [最新 Release](https://github.com/ericwubeta/PrintPet-releases/releases/latest) 获取 Windows x64 安装包或便携 ZIP。

- 已安装 0.5.1：在“精灵与设置 → 版本与更新”检查更新。
- 0.4.1 及更早：手动安装一次最新安装包。
- 已安装本地 0.6.0 内测版：退出程序，手动用 0.5.2 安装包覆盖原目录，保留用户数据。0.6.0 不会自动降级为 0.5.2；本次是正式版本号统一。
- 便携版：保留原 data 目录；改用安装版时需在安装版重新登录。

安装版在打印期间暂缓安装更新。更新检查需要访问 GitHub，客户端不包含开发者 GitHub、拓竹云或模型服务凭据。安装目录与个人设置、账号凭据分开保存；不要将使用后的整个便携目录打包分发。
