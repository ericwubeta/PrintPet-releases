# PrintPet · 打印小监工（桌宠）

用精灵陪你等待 3D 打印完成。支持拓竹云状态查看、进度互动、角色声音与桌面提醒。

本仓库用于 Windows 安装包和签名更新源。源码单独维护。

## 安装与更新

从 [Releases](https://github.com/ericwubeta/PrintPet-releases/releases/latest) 获取 Windows x64 安装包。
v0.4.1 及更早版本需要手动安装一次 v0.4.2，之后可在“精灵与设置 → 版本与更新”中更新。
安装版默认检查新版；打印期间暂缓安装。便携版仅检查新版，保留旧 data 文件夹，在安装版重新登录。

更新检查需要访问 GitHub。客户端不包含 GitHub 账号凭据。
拓竹云连接只读取打印信息，不能控制打印机。
